# SMARTSPEND SA – APPLICATIONS REPORT
SmartSpend SA is a budget management application designed to help users manage their finances more effectively. The application allows users to record their income and expenses, create budgets and monitor their spending from one platform. It was mainly designed for students and individuals who may have limited experience with financial management. The application includes features such as user registration and login, a financial dashboard, budget management and transaction management. Users can enter their income and expenses to better understand their financial situation. SmartSpend SA also uses a local database to store important user information on the device, allowing some features to remain available without an internet connection. An API is also used to support communication between the mobile application and the backend system. During development, simplicity, usability and accessibility were important considerations. Clear navigation, consistent layouts, buttons, headings and input fields were used to make the application easy to understand and use. The forms were kept simple so that users would not need advanced technical knowledge, while the dashboard displays important financial information in one place. Room Database was used for local data storage, while the API supports communication with the backend. Validation and error handling were also included to reduce incorrect information and improve reliability. SmartSpend SA was developed using Kotlin and Jetpack Compose, providing a modern environment for Android application development. The project was organised to make future maintenance and improvements easier. GitHub was used for version control, with the source code and project files stored in a repository. Git commits were used to track changes and maintain a history of the project. GitHub also provides a backup of previous versions, which can be useful if problems occur during development. GitHub Actions was used to automate parts of the development and testing process. Workflows can run when code is pushed to the repository and can be used to build the project, run tests and identify possible errors. This reduces manual work and helps improve the reliability of the application. Overall, SmartSpend SA provides a simple and user-friendly budgeting solution while using local storage, API communication, Kotlin and Jetpack Compose. GitHub and GitHub Actions further support the project through version control, backup, automated testing and organised development.
